# Licensing and asset provenance

Checkpoint source, its documentation, original game visuals, and screenshots of those visuals are provided under the root **MIT license** (copyright 2026 Checkpoint contributors). Each library archive includes its own copy of that license. Package API stability is separate from the license: the API remains experimental.

The expedition's landscape, trees, rocks, courier, beacon, particles, hazards and interface icons are original procedural Canvas/SVG code in `apps/showcase/src/scene.ts` and `main.tsx`. No third-party sprite sheet, game art, stock image, music, audio, downloaded font or model is used. Font names in CSS select fonts installed on the viewer's system; font files are not distributed. Screenshots in `docs/screenshots` show synthetic showcase state. The project name and MIT grant do not imply rights to Twitch/OpenAI/Devpost branding; external service names identify integrations and the event.

Dependencies retain their own copyright and licenses; the root MIT license does **not** relicense them. `@checkpoint/core` has **zero runtime dependencies**. `@checkpoint/twitch` depends on the MIT-licensed core, `ws`, and `zod`. The showcase's direct third-party runtime dependencies (`dotenv`, `express`, `react`, `react-dom`, `ws`, `zod`) declare MIT licenses. Development/build/test tools and transitive dependencies may use different or combined licenses.

`DEPENDENCY_LICENSES.json` inventories the **exact lockfile versions**, declared SPDX/license metadata, development/optional classification and installation location. It includes optional/platform entries even when not installed on this machine. `THIRD_PARTY_NOTICES.txt` preserves available top-level license/copyright/notice text for installed runtime dependencies; missing files are explicitly noted rather than inventing permissions. Upstream packages and their bundled subcomponents remain the authoritative license source. The installed `node_modules` packages retain their original license files. Generated browser bundles also preserve emitted license comments.

After dependency changes, run `npm run licenses` to regenerate these files from the lockfile and installed packages. Review undeclared licenses and nested/bundled components before distributing a different build. A registry metadata inventory is provenance documentation, not legal clearance. Nothing has been published to npm or deployed publicly.
